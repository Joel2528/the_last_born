# Game Controls & Keybindings

| Action | PC Keyboard & Mouse | Gamepad (Xbox/PlayStation) |
| :--- | :--- | :--- |
| **Move** | W, A, S, D | Left Stick |
| **Look / Camera** | Mouse Movement | Right Stick |
| **Sprint** | Left Shift | Left Stick Click (L3) |
| **Jump** | Space | A / Cross |
| **Interact** | E | X / Square |
| **Light Attack** | Left Mouse Button | Right Bumper (RB / R1) |
| **Heavy Attack** | Right Mouse Button | Right Trigger (RT / R2) |
| **Dodge / Roll** | Left Alt | B / Circle |
| **Inventory / Codex** | I / Tab | Touchpad / View Button |
| **Pause Menu** | Escape | Start / Options |

# Installation & Setup Guide

## Prerequisites

- **Unity 2022.3 LTS** (or Unity 6 / Unreal Engine 5.3+)
- **Git** with **Git LFS** enabled
- **Blender 4.0+** (for editing 3D `.blend` source files in `Art/Blender`)

---

## Step 1: Clone the Repository

```bash
git clone https://github.com/[YourOrg]/THE-LAST-BORN.git
cd THE-LAST-BORN
git lfs pull
```

---

## Step 2: Open Project in Unity

1. Open **Unity Hub**.
2. Click **Add** -> **Add project from disk**.
3. Select the `Game/` directory inside `THE-LAST-BORN/`.
4. Launch using Unity 2022.3 LTS.

---

## Step 3: Scene Setup

Navigate to `Game/Scenes/` in Unity's Project Window:
1. `MainMenu.unity` - Main start screen.
2. `Poompuhar.unity` - Primary 3D exploration level.
3. `KumariKandam.unity` - Ancient submerged ruins level.
